What Happens Here?

When TTS.generate(text, voice, stream=True) is called, it loads the model and runs an internal generator loop. On every chunk iteration, it resamples raw MLX audio floats to 24 kHz and yields it immediately back to the caller.

// Key code pattern
for r in self.model.generate(text=text, ...):
    sr = getattr(r, "sample_rate", self.sample_rate)
    yield resample(np.asarray(r.audio, dtype=np.float32), sr, OUT_SR)
